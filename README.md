Conference: IEEE 6th Global Conference (2025)
Authors: RITHIKA S et al.

🚀 Project Overview

This research proposes a hybrid deep learning model combining:

Convolutional Neural Networks (CNN)

Self-Attention Mechanism

Multi-Spectral Imaging

The system classifies fruits and vegetables as Fresh or Rotten under real-world conditions including lighting variation and background noise.
